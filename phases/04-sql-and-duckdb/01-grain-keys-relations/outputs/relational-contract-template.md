## 7. Итог перед первым аналитическим запросом

- [ ] Для каждой таблицы grain сформулирован одним предложением.
- [ ] Primary key соответствует grain, а не просто оказался уникальным в текущем файле.
- [ ] Для составного ключа проверяется полная комбинация.
- [ ] Каждая foreign key направлена от child к уникальному ключу parent.
- [ ] Обязательная и необязательная ссылка различены.
- [ ] Missing-ссылка не смешана с непустым orphan-ключом.
- [ ] Cardinality записана относительно явно названных сторон.
- [ ] Нарушения содержат count и несколько примеров.
- [ ] Ясно, что является blocker, warning и допустимым состоянием.
- [ ] Отдельно названы объявленные, наблюдаемые и реально обеспечиваемые ограничения.
