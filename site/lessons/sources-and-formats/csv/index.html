Один столбец вместо нескольких обычно означает, что фактический delimiter не совпал с параметром парсера.

Почему строка `NULL` не всегда должна автоматически становиться пропуском?

Семантика маркеров пропуска зависит от контракта конкретного источника, а не от написания токена.

CSV и неоднозначность типов

CSV становится данными только после явного договора о байтах, разделителях, пропусках и типах.

Тип: Learn
Треки: Core
Пререквизиты: 04/13
Время: ~75 минут
Результат: объявляет диалект, кодировку, схему и правила пропусков CSV и обнаруживает поврежденные строки до анализа.

Цели обучения

  • Разделять байтовую кодировку, CSV-диалект и табличную схему.
  • Проверять одинаковую ширину строк до типизации значений.
  • Задавать маркеры пропуска и числовой формат как часть контракта источника.
  • Читать CSV в pandas без молчаливого пропуска строк и необратимой ранней инференции.

Как этот урок продолжает маршрут

В 03/02 вы уже отделяли исходный токен от dtype и явной политики пропусков, а в 03/09 и 04/09 требовали у временной метки явный UTC offset. В 04/13 вы находились на стороне поставщика: сами создавали проверенный CSV-пакет вместе с запросом, manifest и checksums.

Теперь роль меняется. Аналитик получает чужой файл без исполняемой истории его создания. Нельзя считать, что расширение .csv доказывает encoding, dialect, типы или даже одинаковую ширину строк. Поэтому прежние контракты не изучаются заново, а переносятся на более раннюю границу:

text
неизвестные байты -> проверенная структура -> проверенные токены -> аналитическая таблица

В 05/02 тот же принцип понадобится для Excel: вместо delimiter придётся явно выбрать лист, диапазон и политику формул.

Проблема

Поставщик прислал файл заказов с расширением .csv. На одной машине он открывается, на другой падает с UnicodeDecodeError, а при pd.read_csv(path) вся строка оказывается в одном столбце. После указания sep=";" суммы всё равно остаются строками:

text
1 200,50
950,00

В комментарии встречается скидка; май, а два пропуска записаны по-разному: пустой строкой и словом NULL. Одна поврежденная строка содержит неэкранированный ;.

Если решить проблемы набором случайных параметров, файл может загрузиться, но результат не станет проверяемым. Опасные варианты:

  • декодировать с errors="replace" и потерять исходные символы;
  • использовать неверный delimiter и получить один широкий столбец;
  • включить on_bad_lines="skip" и незаметно потерять заказ;
  • разрешить parser inference превратить идентификатор или маркер пропуска не в тот тип;
  • удалить запятые, смешав разделитель полей и десятичный знак.

Концепция

CSV не хранит единую самодостаточную схему. Для воспроизводимого чтения нужны четыре отдельных договора.

Слой Вопрос Пример
Encoding Как байты превращаются в символы? cp1251
Dialect Как символы делятся на поля и строки? delimiter ;, quotechar "
Null policy Какие токены означают отсутствие значения? "", NULL
Schema Какие столбцы и типы ожидаются? amount: decimal, non-null

Encoding применяется раньше CSV-парсера. Если байты CP1251 попытаться строго декодировать как UTF-8, ошибка полезна: она останавливает порчу данных. Символ замены � не является исправлением.

Dialect определяет delimiter, quotechar, правила двойных кавычек и пробелов. Символ delimiter внутри quoted field не создаёт новое поле:

csv
O2002;U002;2026-05-02T08:30:00Z;950,00;RUB;"скидка; май"

Null policy является семантикой источника. Токен NULL иногда означает пропуск, а иногда является настоящей строкой. Автоматический словарь NA нельзя считать универсальным. Контракт этого урока намеренно задаёт один список маркеров для всего файла. Если один и тот же токен означает пропуск только в части столбцов, источник требует отдельной поколоночной политики — глобальный список нельзя применять молча.

Schema применяется после структурной проверки. Сначала нужно доказать, что заголовок и ширина строк согласованы, затем приводить amount и ordered_at. Для ordered_at контракт повторяет уже знакомое правило: непустая ISO 8601 строка должна содержать Z или числовой UTC offset.

Число строк — отдельная проверка поставки, а не обязательное свойство формата CSV. Для фиксированного выгружаемого пакета можно потребовать ровно пять строк. Для ежедневного источника допустимо задать только минимум или вообще не объявлять row-count policy: непредсказуемый объём нельзя превращать в ложную ошибку схемы.

В учебной поставке эти два решения видны прямо в JSON-контракте:

json
{
  "row_count": {"mode": "exact", "value": 5},
  "columns": {
    "ordered_at": {
      "type": "timestamp",
      "nullable": false,
      "require_timezone": true
    }
  }
}

Для меняющегося потока замените exact на осмысленный min либо удалите row_count. require_timezone: true не угадывает зону naive-строки, а требует, чтобы источник передал однозначный момент.

csv.Sniffer и parser inference полезны для разведки, но эвристика не заменяет контракт: результат угадывания нужно проверить и зафиксировать.

Соберите это

Committed fixture использует CP1251, ;, десятичную запятую и пробел тысяч.

Шаг 1. Декодируйте строго

python
raw = path.read_bytes()
text = raw.decode("cp1251", errors="strict")

strict превращает неверную кодировку в наблюдаемую ошибку. Не используйте errors="ignore" или errors="replace" в quality gate.

Шаг 2. Сравните наивный и явный dialect

Парсер по умолчанию ожидает запятую:

python
naive_header = next(csv.reader(io.StringIO(text)))

В учебном файле он видит один field. Явный delimiter восстанавливает шесть:

python
reader = csv.DictReader(
    io.StringIO(text),
    delimiter=";",
    quotechar='"',
)

Шаг 3. Проверьте ширину каждой строки

До создания словаря сравните фактическое число полей с заголовком:

python
if len(row) != len(header):
    raise ValueError(
        f"line {reader.line_num}: expected {len(header)}, got {len(row)}"
    )

Номер строки и обе ширины важнее сообщения «CSV сломан»: они позволяют найти источник дефекта, не удаляя наблюдение.

Шаг 4. Примените числовой договор

Для 1 200,50 сначала проверьте форму токена, а уже потом удаляйте договорный разделитель:

python
number = re.compile(r"[+-]?(?:[0-9]+|[0-9]{1,3}(?: [0-9]{3})+)(?:,[0-9]+)?")
if number.fullmatch(value) is None:
    raise ValueError(f"invalid decimal format: {value!r}")

normalized = value.replace(" ", "").replace(",", ".")
amount = Decimal(normalized)
if not amount.is_finite():
    raise ValueError(f"decimal must be finite: {value!r}")

Порядок принципиален. Если сразу удалить все пробелы, повреждённое 12 00,50 молча станет правдоподобным 1200.50. Это не универсальная очистка строк, а преобразование, разрешённое конкретным контрактом после проверки его формы.

Запустите прозрачный пример:

bash
uv run --locked python code/main.py

Он показывает, что наивное чтение видит один столбец, явное — шесть, quoted delimiter остаётся внутри комментария, а сумма после договорного преобразования равна 3226.59.

Используйте это

pandas читает тот же файл только после фиксации структуры:

python
frame = pd.read_csv(
    path,
    encoding="cp1251",
    sep=";",
    quotechar='"',
    dtype="string",
    keep_default_na=False,
    na_filter=False,
    on_bad_lines="error",
)

Первый проход намеренно сохраняет исходные токены как строки:

  • dtype="string" откладывает типизацию;
  • keep_default_na=False и na_filter=False не расширяют null policy;
  • on_bad_lines="error" не разрешает молчаливую потерю строк;
  • encoding и dialect не зависят от локали машины.

После структурного gate можно отдельно применить null_values, decimal, thousands, timestamp parser и domain checks.

Самостоятельный аудитор выполняет оба слоя:

bash
uv run --locked python outputs/csv_audit.py \
  --input ../data/tiny/orders_semicolon_cp1251.csv \
  --contract ../data/contract.json

JSON-отчёт содержит:

  • размер и SHA-256 исходных байтов;
  • объявленную кодировку и обнаруженный BOM;
  • фактический и ожидаемый заголовок;
  • malformed rows с номером строки и шириной;
  • null и invalid counts по каждому столбцу;
  • соблюдение явной timezone policy для timestamp;
  • результат необязательной row-count policy exact или min;
  • результат строгого чтения pandas;
  • итоговый valid и число проваленных проверок.

Коды возврата:

  • 0 — файл соответствует контракту;
  • 1 — файл прочитан, но данные или структура нарушают контракт;
  • 2 — файл или контракт нельзя проверить;
  • 0 с --allow-failures — учебный просмотр известного дефекта.

Поставьте результат

outputs/csv_audit.py — самостоятельный CLI для preflight-проверки внешнего CSV. Он получает путь к файлу и JSON-контракт, не зависит от текста урока и подходит как локальный gate перед pandas/DuckDB или как шаг CI.

Артефакт не исправляет данные автоматически. Его задача — доказать, какой договор выполнен, и точно локализовать расхождение. Глобальная null policy и поддержанные типы являются осознанной границей этого небольшого аудитора, а не заявкой на универсальный schema registry.

Упражнения

  1. Добавьте тип boolean с явными токенами true_values и false_values.
  2. Расширьте контракт допустимыми категориями currency и покажите неизвестное значение.
  3. Добавьте режим сравнения двух CSV-контрактов и отчёт о schema drift.

Сопоставьте delimiter, quotechar, doublequote, skipinitialspace и strict с JSON-контрактом урока и обратите внимание, что документация прямо называет Sniffer грубой эвристикой.
  • pandas: read_csv — разберите параметры dtype, na_values, keep_default_na, na_filter, decimal, thousands, encoding_errors и on_bad_lines. Затем для каждого параметра в примере урока сформулируйте, какую часть контракта он реализует и почему первичное чтение оставляет все токены строками.
  • Microsoft Learn: соединитель Power Query Text/CSV — в русскоязычной официальной документации прочитайте разделы Разделители текста и CSV и Устранение неполадок, особенно обнаружение типов по первым 200 строкам, всему файлу или его отключение. Это переносит проблему parser inference из Python в знакомые Excel и Power BI и показывает, как зафиксированное число столбцов влияет на последующие обновления.

Документация показывает, что NaN и Infinity являются допустимыми объектами Decimal, поэтому контракт денежного столбца обязан отдельно проверять форму токена и конечность значения.
  • Python: datetime — прочитайте Aware and naive objects и примеры datetime.fromisoformat(). Сравните результаты для строки без offset, с Z и с +03:00: сам parser принимает и naive-, и aware-время, а требование однозначного момента остаётся ответственностью контракта источника.
  • Postgres Pro: команда COPY — в русскоязычном разделе Формат CSV разберите DELIMITER, QUOTE, NULL, FORCE_NULL и FORCE_NOT_NULL, а также ошибки разной ширины записей. Особенно полезно сравнение пустой строки и SQL NULL: оно показывает реальную поколоночную политику, которая сознательно не реализована в небольшом аудиторе урока.
  • RFC 4180: Common Format and MIME Type for CSV Files — прочитайте разделы 2. Definition of the CSV Format и 3. MIME Type Registration. Используйте документ как распространённую точку совместимости для заголовка, одинаковой ширины и quoting, но не как доказательство, что любой файл с расширением .csv обязан следовать одному диалекту.
  • Yandex Cloud: передача данных из эндпоинта-источника S3 — в разделе Настройки найдите JSON-схему и параметры CSV: delimiter, quote, escape, encoding, double quote и переносы строк внутри значений. Страница показывает, что те же решения становятся явной конфигурацией промышленного ingestion-инструмента, а не остаются деталями pd.read_csv.
  • W3C: Model for Tabular Data and Metadata on the Web — для углубления прочитайте 6.4 Parsing Cells, 7. Best Practice CSV и начало 8. Parsing Tabular Data. Модель связывает исходную строку, datatype, null, required, dialect и validation errors и показывает, как учебный JSON-контракт можно развить до переносимых метаданных без попытки угадывать смысл файла.

Проверьте себя

Ответьте после практики. Объяснение появится сразу после выбора.

01

В столбце суммы встретился токен `12 00,50`, а контракт разрешает пробел как разделитель тысяч. Как должен поступить аудитор?

Сначала проверяется лексическая форма числа. Иначе произвольное удаление разделителей превращает поврежденный токен в правдоподобное значение.

02

Что должен сделать quality gate со строкой, в которой семь полей вместо ожидаемых шести?

Молчаливое исправление или пропуск меняют данные; нарушение ширины должно быть наблюдаемым.

03

Почему `dtype="string"` полезен на первом чтении неизвестного CSV?

Первичное строковое чтение не смешивает структурный парсинг с необратимой автоматической типизацией.

04

Ежедневный CSV имеет стабильную схему, но законное число заказов меняется. Как выразить проверку количества строк?

Точное число строк является договором конкретной поставки, а не свойством CSV. Для меняющегося потока подходит минимум или отсутствие row-count policy.

def normalize_decimal(value: str, decimal_mark: str, thousands: str) -> Decimal:
    grouped = rf"[0-9]{{1,3}}(?:{re.escape(thousands)}[0-9]{{3}})+"
    integer = rf"(?:[0-9]+|{grouped})"
    fraction = rf"(?:{re.escape(decimal_mark)}[0-9]+)?"
    if re.fullmatch(rf"[+-]?{integer}{fraction}", value) is None:
        raise ValueError(f"invalid decimal format: {value!r}")

    parsed = Decimal(normalized)
    if not parsed.is_finite():
        raise ValueError(f"decimal must be finite: {value!r}")
    return parsed

from __future__ import annotations

import argparse
import codecs
import csv
import hashlib
import io
import json
import re
import sys
from datetime import datetime
from decimal import Decimal, InvalidOperation
from pathlib import Path
from typing import Any

import pandas as pd

SUPPORTED_TYPES = {"string", "integer", "decimal", "timestamp"}
BOMS = (
    (codecs.BOM_UTF32_LE, "utf-32-le"),
    (codecs.BOM_UTF32_BE, "utf-32-be"),
    (codecs.BOM_UTF8, "utf-8"),
    (codecs.BOM_UTF16_LE, "utf-16-le"),
    (codecs.BOM_UTF16_BE, "utf-16-be"),
)


class CsvContractError(ValueError):
    """Raised when a CSV contract or input path cannot be audited."""


def load_contract(path: str | Path) -> dict[str, Any]:
    contract_path = Path(path)
    if not contract_path.is_file():
        raise CsvContractError(f"contract file does not exist: {contract_path}")
    try:
        contract = json.loads(contract_path.read_text(encoding="utf-8"))
    except json.JSONDecodeError as error:
        raise CsvContractError(f"invalid contract JSON: {error.msg}") from error
    return validate_contract(contract)


def validate_contract(contract: Any) -> dict[str, Any]:
    if not isinstance(contract, dict):
        raise CsvContractError("contract must be a JSON object")

    encoding = contract.get("encoding")
    if not isinstance(encoding, str) or not encoding:
        raise CsvContractError("contract must declare a non-empty encoding")
    try:
        codecs.lookup(encoding)
    except LookupError as error:
        raise CsvContractError(f"unknown encoding: {encoding}") from error

    dialect = contract.get("dialect")
    if not isinstance(dialect, dict):
        raise CsvContractError("contract must declare a dialect object")
    for field in ("delimiter", "quotechar"):
        value = dialect.get(field)
        if not isinstance(value, str) or len(value) != 1:
            raise CsvContractError(f"dialect.{field} must contain one character")
    for field in ("doublequote", "skipinitialspace"):
        if not isinstance(dialect.get(field), bool):
            raise CsvContractError(f"dialect.{field} must be boolean")

    null_values = contract.get("null_values")
    if not isinstance(null_values, list) or not all(
        isinstance(value, str) for value in null_values
    ):
        raise CsvContractError("null_values must be a list of strings")

    number_format = contract.get("number_format")
    if not isinstance(number_format, dict):
        raise CsvContractError("contract must declare number_format")
    decimal_mark = number_format.get("decimal")
    thousands = number_format.get("thousands")
    if not isinstance(decimal_mark, str) or len(decimal_mark) != 1:
        raise CsvContractError("number_format.decimal must contain one character")
    if not isinstance(thousands, str) or len(thousands) > 1:
        raise CsvContractError("number_format.thousands must contain at most one character")
    if thousands and thousands == decimal_mark:
        raise CsvContractError("decimal and thousands separators must differ")

    columns = contract.get("columns")
    if not isinstance(columns, dict) or not columns:
        raise CsvContractError("contract must declare a non-empty columns object")
    for name, column in columns.items():
        if not isinstance(name, str) or not name:
            raise CsvContractError("column names must be non-empty strings")
        if not isinstance(column, dict):
            raise CsvContractError(f"column contract must be an object: {name}")
        column_type = column.get("type")
        if column_type not in SUPPORTED_TYPES:
            raise CsvContractError(f"unsupported type for {name}: {column.get('type')}")
        if not isinstance(column.get("nullable"), bool):
            raise CsvContractError(f"column {name} must declare nullable")
        if column_type == "timestamp" and not isinstance(column.get("require_timezone"), bool):
            raise CsvContractError(f"timestamp column {name} must declare require_timezone")

    row_count = contract.get("row_count")
    if row_count is not None:
        if not isinstance(row_count, dict):
            raise CsvContractError("row_count must be an object when declared")
        if row_count.get("mode") not in {"exact", "min"}:
            raise CsvContractError("row_count.mode must be exact or min")
        if type(row_count.get("value")) is not int or row_count["value"] < 0:
            raise CsvContractError("row_count.value must be a non-negative integer")
    if contract.get("header") is not True:
        raise CsvContractError("this auditor requires header=true")
    return contract


def detect_bom(raw: bytes) -> str | None:
    for prefix, name in BOMS:
        if raw.startswith(prefix):
            return name
    return None


def parse_decimal(
    value: str,
    *,
    decimal_mark: str,
    thousands: str,
) -> Decimal:
    sign = r"[+-]?"
    digits = r"[0-9]+"
    if thousands:
        grouped = rf"[0-9]{{1,3}}(?:{re.escape(thousands)}[0-9]{{3}})+"
        integer = rf"(?:{digits}|{grouped})"
    else:
        integer = digits
    fraction = rf"(?:{re.escape(decimal_mark)}[0-9]+)?"
    if re.fullmatch(rf"{sign}{integer}{fraction}", value) is None:
        raise ValueError(f"invalid decimal format: {value!r}")

    normalized = value.replace(thousands, "") if thousands else value
    if decimal_mark != ".":
        normalized = normalized.replace(decimal_mark, ".")
    try:
        parsed = Decimal(normalized)
    except InvalidOperation as error:
        raise ValueError(f"invalid decimal: {value!r}") from error
    if not parsed.is_finite():
        raise ValueError(f"decimal must be finite: {value!r}")
    return parsed


def parse_timestamp(value: str, *, require_timezone: bool) -> datetime:
    normalized = value[:-1] + "+00:00" if value.endswith("Z") else value
    try:
        parsed = datetime.fromisoformat(normalized)
    except ValueError as error:
        raise ValueError(f"invalid ISO timestamp: {value!r}") from error
    if require_timezone and parsed.utcoffset() is None:
        raise ValueError(f"timestamp must contain an explicit UTC offset: {value!r}")
    return parsed


def validate_value(value: str, column: dict[str, Any], contract: dict[str, Any]) -> None:
    value_type = column["type"]
    if value_type == "string":
        return
    if value_type == "integer":
        int(value)
        return
    if value_type == "decimal":
        number_format = contract["number_format"]
        parse_decimal(
            value,
            decimal_mark=number_format["decimal"],
            thousands=number_format["thousands"],
        )
        return
    if value_type == "timestamp":
        parse_timestamp(value, require_timezone=column["require_timezone"])
        return
    raise CsvContractError(f"unsupported type: {value_type}")


def inspect_rows(text: str, contract: dict[str, Any]) -> dict[str, Any]:
    expected_columns = list(contract["columns"])
    dialect = contract["dialect"]
    reader = csv.reader(
        io.StringIO(text, newline=""),
        delimiter=dialect["delimiter"],
        quotechar=dialect["quotechar"],
        doublequote=dialect["doublequote"],
        skipinitialspace=dialect["skipinitialspace"],
        strict=True,
    )

    parse_errors: list[dict[str, Any]] = []
    try:
        header = next(reader)
    except StopIteration:
        header = []
        parse_errors.append({"line": 1, "error": "empty CSV"})
    except csv.Error as error:
        header = []
        parse_errors.append({"line": reader.line_num or 1, "error": str(error)})

    duplicate_headers = sorted({name for name in header if header.count(name) > 1})
    missing_columns = [name for name in expected_columns if name not in header]
    unexpected_columns = [name for name in header if name not in expected_columns]
    order_matches = header == expected_columns

    rows: list[tuple[int, dict[str, str]]] = []
    malformed_rows: list[dict[str, Any]] = []
    data_rows = 0
    if header:
        try:
            for row in reader:
                data_rows += 1
                if len(row) != len(header):
                    malformed_rows.append(
                        {
                            "line": reader.line_num,
                            "expected_fields": len(header),
                            "actual_fields": len(row),
                            "values": row,
                        }
                    )
                    continue
                rows.append((reader.line_num, dict(zip(header, row, strict=True))))
        except csv.Error as error:
            parse_errors.append({"line": reader.line_num, "error": str(error)})

    row_count_policy = contract.get("row_count")
    row_count_matches = check_row_count(data_rows, row_count_policy)
    header_valid = (
        not duplicate_headers and not missing_columns and not unexpected_columns and order_matches
    )
    return {
        "header": header,
        "expected_header": expected_columns,
        "duplicate_headers": duplicate_headers,
        "missing_columns": missing_columns,
        "unexpected_columns": unexpected_columns,
        "order_matches": order_matches,
        "data_rows": data_rows,
        "row_count_policy": row_count_policy,
        "row_count_matches": row_count_matches,
        "malformed_rows": malformed_rows[:5],
        "parse_errors": parse_errors,
        "records": rows,
        "valid": header_valid and row_count_matches and not malformed_rows and not parse_errors,
    }


def inspect_columns(
    rows: list[tuple[int, dict[str, str]]],
    contract: dict[str, Any],
) -> dict[str, Any]:
    null_values = set(contract["null_values"])
    report: dict[str, Any] = {}
    for name, column in contract["columns"].items():
        null_count = 0
        invalid: list[dict[str, Any]] = []
        for line, row in rows:
            if name not in row:
                continue
            value = row[name]
            if value in null_values:
                null_count += 1
                if not column["nullable"]:
                    invalid.append({"line": line, "value": value, "error": "null is forbidden"})
                continue
            try:
                validate_value(value, column, contract)
            except (TypeError, ValueError) as error:
                invalid.append({"line": line, "value": value, "error": str(error)})
        report[name] = {
            "type": column["type"],
            "nullable": column["nullable"],
            "null_count": null_count,
            "invalid_count": len(invalid),
            "sample_invalid": invalid[:5],
            "valid": not invalid,
        }
    return report


def check_row_count(actual: int, policy: dict[str, Any] | None) -> bool:
    if policy is None:
        return True
    if policy["mode"] == "exact":
        return actual == policy["value"]
    return actual >= policy["value"]


def inspect_with_pandas(path: Path, contract: dict[str, Any]) -> dict[str, Any]:
    dialect = contract["dialect"]
    try:
        frame = pd.read_csv(
            path,
            encoding=contract["encoding"],
            sep=dialect["delimiter"],
            quotechar=dialect["quotechar"],
            doublequote=dialect["doublequote"],
            skipinitialspace=dialect["skipinitialspace"],
            dtype="string",
            keep_default_na=False,
            na_filter=False,
            on_bad_lines="error",
        )
    except (OSError, UnicodeError, pd.errors.ParserError) as error:
        return {"loaded": False, "error": str(error), "valid": False}
    return {
        "loaded": True,
        "rows": len(frame),
        "columns": frame.columns.tolist(),
        "dtypes": {name: str(dtype) for name, dtype in frame.dtypes.items()},
        "preview": frame.head(3).to_dict(orient="records"),
        "valid": frame.columns.tolist() == list(contract["columns"])
        and check_row_count(len(frame), contract.get("row_count")),
    }


def audit_csv(input_path: str | Path, contract_path: str | Path) -> dict[str, Any]:
    path = Path(input_path)
    if not path.is_file():
        raise CsvContractError(f"input file does not exist: {path}")
    contract = load_contract(contract_path)
    raw = path.read_bytes()
    encoding_report: dict[str, Any] = {
        "declared": contract["encoding"],
        "bom": detect_bom(raw),
        "valid": True,
        "error": None,
    }
    try:
        text = raw.decode(contract["encoding"], errors="strict")
    except UnicodeDecodeError as error:
        text = None
        encoding_report.update(
            {
                "valid": False,
                "error": f"cannot decode byte {error.start} as {contract['encoding']}",
            }
        )

    if text is None:
        structure = {
            "valid": False,
            "error": "structure was not inspected because decoding failed",
            "records": [],
        }
        columns = {
            name: {
                "type": column["type"],
                "nullable": column["nullable"],
                "null_count": None,
                "invalid_count": None,
                "sample_invalid": [],
                "valid": False,
            }
            for name, column in contract["columns"].items()
        }
        pandas_report = {"loaded": False, "error": "decoding failed", "valid": False}
    else:
        structure = inspect_rows(text, contract)
        columns = inspect_columns(structure["records"], contract)
        pandas_report = inspect_with_pandas(path, contract)

    structure_for_output = {key: value for key, value in structure.items() if key != "records"}
    checks = {
        "encoding": encoding_report["valid"],
        "structure": structure_for_output["valid"],
        "columns": all(column["valid"] for column in columns.values()),
        "pandas": pandas_report["valid"],
    }
    return {
        "source": str(path),
        "bytes": len(raw),
        "sha256": hashlib.sha256(raw).hexdigest(),
        "encoding": encoding_report,
        "dialect": contract["dialect"],
        "null_values": contract["null_values"],
        "structure": structure_for_output,
        "columns": columns,
        "pandas": pandas_report,
        "summary": {
            "checks": checks,
            "failed_checks": sum(not valid for valid in checks.values()),
            "valid": all(checks.values()),
        },
    }


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(description="Audit CSV against an explicit contract")
    parser.add_argument("--input", required=True, type=Path)
    parser.add_argument("--contract", required=True, type=Path)
    parser.add_argument("--allow-failures", action="store_true")
    return parser


def main() -> int:
    args = build_parser().parse_args()
    try:
        report = audit_csv(args.input, args.contract)
    except (CsvContractError, OSError) as error:
        print(f"error: {error}", file=sys.stderr)
        return 2
    print(json.dumps(report, ensure_ascii=False, indent=2, sort_keys=True))
    if report["summary"]["valid"] or args.allow_failures:
        return 0
    return 1


if __name__ == "__main__":
    raise SystemExit(main())
