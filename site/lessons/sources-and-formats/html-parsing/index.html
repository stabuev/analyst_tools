HTML и Beautiful Soup

Селектор — это не просто способ достать значение. Это проверяемое предположение о структуре страницы, которое должно остановить поставку при нарушении.

Тип: Case

Пререквизиты: 05/05
Время: ~60 минут

Цели обучения

После урока вы сможете:

  • отдельно задать источник значения, его тип и допустимую cardinality селектора;
  • обнаружить пропавшее, неоднозначное или невалидное поле до публикации данных;
  • сохранить один самостоятельный snapshot с записями, проверками и provenance.

Проблема

Почему «нашёл первый узел» недостаточно

В 05/05 мы получили все страницы API и сохранили результат только после доказанного завершения пагинации. Но источник не всегда предоставляет JSON API. Представим, что владелец системы разрешил использовать сохранённую HTML-страницу со списком заказов. Наша задача — превратить карточки в строки:

order_id user_id amount
O2601 U001 1200.50
O2602 U002 950.00

Наивный скрипт вызывает select_one() для каждого поля. После редизайна второй data-field="amount" меняется на data-field="total". Скрипт либо падает далеко от причины, либо подставляет None, а затем всё равно записывает файл. Обе реакции плохи:

  • падение не называет нарушенное предположение;
  • тихий None превращает drift разметки в правдоподобные испорченные данные;
  • частичный файл может заменить предыдущий валидный snapshot.

Нужен не «скрейпер, который иногда работает», а маленький проверяемый конвейер:

text
saved UTF-8 bytes
  → parse tree с фиксированным parser
  → ровно один container
  → набор record nodes
  → ровно один node на обязательное field
  → явные types и grain
  → проверки
  → атомарная публикация

Урок работает только с сохранёнными fixtures. HTTP, retries и получение разрешения на доступ уже не смешиваются с разбором HTML: так сбой транспорта не маскируется под сбой селектора.

Концепция

Три разных представления страницы

1. Исходные bytes

Файл orders.html — последовательность байтов. До парсинга мы:

  1. ограничиваем размер;
  2. декодируем bytes как строгий UTF-8;
  3. считаем SHA-256 именно исходных bytes.

Это позволяет связать результат с конкретным входом. Хеш уже распарсенного текста был бы слабее: разные исходные bytes могут превратиться в похожее представление.

2. Parse tree Beautiful Soup

BeautifulSoup(text, "html.parser") передаёт строку выбранному parser и строит дерево Python-объектов. Теги становятся Tag, текст — строковыми узлами. Невалидный HTML parser может исправить; разные parsers способны построить разные деревья. Поэтому имя parser — часть контракта и provenance, а не локальная деталь окружения.

3. DOM браузера

Браузер тоже парсит HTML, но затем может выполнить JavaScript, изменить DOM и дорисовать данные. Beautiful Soup JavaScript не выполняет. Если искомой карточки нет в сохранённом HTML, но она появляется после выполнения скрипта, текущий инструмент её не увидит.

Это сознательная граница урока. Мы не добавляем browser automation «на всякий случай». Сначала следует поискать официальный API, export или HTML, который уже содержит данные. Playwright/Selenium нужны только для отдельной доказанной задачи, а не для исправления непонятного селектора.

HTML как дерево

В fixture одна запись выглядит так:

html
<article data-order-card data-order-id="O2601">
  <span data-field="user">U001</span>
  <span data-field="amount">1200.50</span>
</article>

Здесь есть три разных источника значений:

  • имя тега: article, span;
  • attribute: data-order-id="O2601";
  • text внутри тега: 1200.50.

CSS selector отвечает только на вопрос «какие узлы подходят». Он не решает, откуда взять значение и каким типом оно должно стать.

Почему поиск должен быть scoped

Селектор [data-field='amount'] по всему документу найдёт суммы из всех карточек. Нам нужна цепочка областей:

  1. [data-orders] — единственный контейнер нужного списка;
  2. [data-order-card] — записи только внутри этого контейнера;
  3. [data-field='amount'] — поле только внутри текущей записи.

Так одинаковое имя поля в боковой панели или шаблоне страницы не попадёт в таблицу.

Устойчивость селектора условна

Обычно div > div:nth-child(2) хрупче, чем семантический data-*, потому что первый описывает визуальное положение, а второй может выражать назначение. Но data-* не даёт гарантии: владелец страницы также может его переименовать. Устойчивость появляется из сочетания:

  • осмысленного selector;
  • сохранённого fixture;
  • проверки cardinality;
  • явного отказа от публикации при drift.

Selector contract

../data/html_contract.json отделяет правила извлечения от кода:

json
{
  "version": "2.0.0",
  "parser": "html.parser",
  "encoding": "utf-8",
  "container_selector": "[data-orders]",
  "record_selector": "[data-order-card]",
  "record_count": {"mode": "exact", "value": 2},
  "record_id": {"name": "order_id", "attribute": "data-order-id"},
  "fields": {
    "user_id": {
      "selector": "[data-field='user']",
      "source": "text",
      "type": "string",
      "non_blank": true
    },
    "amount": {
      "selector": "[data-field='amount']",
      "source": "text",
      "type": "decimal",
      "non_blank": true
    }
  }
}

Контракт отвечает на отдельные вопросы:

Часть Вопрос
version Какую форму контракта понимает extractor?
parser, encoding Как именно bytes превращаются в дерево?
container_selector Где начинается нужный список?
record_selector Какой узел соответствует одной записи?
record_count Сколько записей допустимо в этом fixture?
record_id Как называется ключ grain и из какого attribute он берётся?
fields.*.selector Как найти узел поля внутри записи?
source Читать text или named attribute?
type, non_blank Как проверить найденное значение?

Неизвестные ключи и неподдерживаемая версия запрещены. Иначе опечатка вроде record_selecter могла бы выглядеть как настройка, хотя код её игнорирует.

select() вместо преждевременного select_one()

Для обязательного поля допустима cardinality ровно 1:

python
matches = card.select("[data-field='amount']")
if len(matches) != 1:
    # 0 — поле пропало; 2+ — поле стало неоднозначным
    report_failure()

select_one() сразу оставляет только первое совпадение. Это удобно для исследования, но скрывает дубликат в проверяемом pipeline.

text и attribute — разные контракты

Для <span data-field="amount">1200.50</span> значение берётся из text. Для <a data-user-id="U001">Анна</a> аналитическим ключом может быть attribute data-user-id, а видимый текст — подписью. Эти варианты нельзя угадывать по наличию атрибута: источник значения объявляется явно.

Типизация после извлечения

amount разбирается как Decimal, а не float. Контракт урока принимает обычную десятичную запись с точкой и отвергает NaN, Infinity, экспоненциальную запись и десятичную запятую. Если источник использует другой формат, это нужно описать отдельным правилом, а не расширять parser молча.

Grain и record count

Grain результата — одна строка на order_id. Поэтому недостаточно найти карточки:

  • order_id должен присутствовать и быть непустым;
  • order_id должен быть уникальным;
  • каждое обязательное поле должно быть валидно;
  • число records должно удовлетворять выбранной политике.

Для regression fixture используется exact: 2: любое добавление или исчезновение карточки означает, что fixture или ожидаемый результат надо осознанно пересмотреть. Для регулярной страницы можно выбрать min: N, если рост списка нормален, но исчезновение всех записей всё равно должно быть заметно. Политика числа строк не заменяет проверку grain и полей.

Соберите это

Разберите путь вручную

Запустите короткий прозрачный пример из директории урока:

bash
uv run --locked python code/main.py

Он делает пять видимых шагов:

  1. читает сохранённые bytes;
  2. строго декодирует UTF-8;
  3. требует ровно один container;
  4. показывает mapping каждой карточки в словарь;
  5. запускает самостоятельный contract-driven artifact и печатает его checks.

Функция exactly_one() намеренно мала. Она показывает механизм, который часто теряется за удобным select_one():

python
def exactly_one(scope, selector, label):
    matches = scope.select(selector)
    if len(matches) != 1:
        raise ValueError(f"{label}: expected one match, got {len(matches)}")
    return matches[0]

В production artifact вместо первого исключения собирается полный audit report: так за один запуск видны все записи и поля, которые потребуют разбора.

Используйте это

Проверьте и опубликуйте snapshot

Из директории урока выполните:

bash
uv run --locked python outputs/html_extractor.py \
  --input ../data/tiny/orders.html \
  --contract ../data/html_contract.json \
  --output delivery/orders_snapshot.json

Успешный запуск возвращает код 0 и атомарно создаёт один JSON-файл. В нём находятся:

  • records с двумя строками;
  • точная копия применённого selector contract;
  • file names, SHA-256 и размер исходного HTML;
  • SHA-256 файла контракта;
  • counts селекторов, checks и errors;
  • summary.valid=true и summary.published=true.

Локальные абсолютные пути в provenance не записываются: snapshot можно передать другому человеку без утечки структуры домашней директории.

Почему один snapshot, а не JSONL плюс отдельный report

Если записи и отчёт заменяются двумя независимыми операциями, потребитель может увидеть новые records со старым report. Один self-contained файл образует единую версию данных и доказательств. Временный файл создаётся рядом с target, синхронизируется и заменяет предыдущий snapshot через os.replace() только после успешных checks.

Сломайте это

Вызовите selector drift

Fixture orders_changed.html меняет поле суммы второго заказа:

html
<strong data-field="total">950.00</strong>

Запустите аудит без публикации:

bash
uv run --locked python outputs/html_extractor.py \
  --input ../data/tiny/orders_changed.html \
  --contract ../data/html_contract.json

Ожидаемый код возврата — 1. В errors будут record 2, record_id=O2602, поле amount, исходный selector и matches=0.

Флаг --allow-failures нужен только для диагностического batch-аудита:

bash
uv run --locked python outputs/html_extractor.py \
  --input ../data/tiny/orders_changed.html \
  --contract ../data/html_contract.json \
  --output delivery/must-not-exist.json \
  --allow-failures

Команда вернёт 0, чтобы вызывающий процесс мог продолжить сбор отчётов, но файл must-not-exist.json не появится. allow failures никогда не означает allow bad data.

Попробуйте ещё четыре поломки:

  1. удалите data-orders или создайте второй container;
  2. продублируйте amount внутри одной карточки;
  3. повторите order_id у двух карточек;
  4. замените 950.00 на NaN или 1,20.

В каждом случае спросите: нарушена структура документа, cardinality, grain или тип?

Проверьте это

Докажите поведение

bash
uv run --locked python -m unittest discover -s tests

Behavioral tests проверяют не только happy path, но и:

  • отсутствие и неоднозначность container;
  • exact/min policy числа records;
  • пропавшие, пустые и дублирующиеся IDs;
  • ноль и два совпадения обязательного field;
  • text и attribute sources;
  • пустые строки и недопустимые decimals;
  • invalid UTF-8, charset drift и лимит bytes;
  • invalid selectors, версии, неизвестные и duplicate JSON keys;
  • self-contained provenance;
  • запрет публикации invalid result и сохранность предыдущего файла;
  • отсутствие временного файла после atomic replace;
  • коды CLI и диагностическую семантику --allow-failures.

Fixture test не доказывает, что внешний сайт никогда не изменится. Он доказывает более узкое и полезное утверждение: при известном входе extractor даёт ожидаемый результат, а при известных нарушениях блокирует поставку.

Поставьте результат

Передайте воспроизводимый результат

Именованный артефакт урока — outputs/html_extractor.py. Для handoff передайте:

  1. сохранённый HTML или способ независимо получить именно его;
  2. html_contract.json;
  3. созданный orders_snapshot.json;
  4. команду запуска и версию locked-окружения;
  5. решение владельца данных о допустимом способе доступа.

Получатель snapshot может без исходного рабочего каталога увидеть records, контракт, parser, encoding, checks и checksums. Для повторной проверки ему всё ещё нужны исходный HTML и contract bytes: checksum подтверждает совпадение, но не восстанавливает источник.

Границы безопасного применения

Техническая возможность прочитать HTML не означает разрешение собирать данные. Перед работой с внешним сайтом уточните официальный API/export, условия использования, договорённость с владельцем и применимые ограничения. robots.txt стандартизует правила для crawler-ов, но не является механизмом авторизации и сам по себе не выдаёт право доступа.

Этот урок не охватывает:

  • обход сайта и очереди URL;
  • авторизацию, cookies и персональные данные;
  • JavaScript rendering и browser automation;
  • anti-bot обходы;
  • автоматическую «починку» selectors по догадке.

При drift правильная первая реакция — остановить поставку, изучить новый fixture и согласованно изменить contract, tests и его version.

Упражнения

  1. Измените user_id так, чтобы он читался из data-user-id, и добавьте fixture test.
  2. Переключите record_count с exact на min; объясните, какую поломку теперь не обнаружит один только count check.
  3. Спроектируйте политику optional field: как отличить допустимое отсутствие от drift и как оно должно выглядеть в report? Не меняйте основной контракт, пока правило не сформулировано.
  4. Разберите намеренно повреждённый HTML с html.parser и другим parser. Сравните построенные деревья, не объявляя одно из них «истиной» без контракта источника.

Дополнительное чтение

  • MDN: основы синтаксиса HTML — закрепите различие элемента, тега, содержимого и атрибута на русскоязычных примерах.
  • MDN: CSS-селекторы — используйте как карту типов селекторов и сначала освойте простые attribute selectors.
  • MDN: использование data-атрибутов — разберите назначение data-* и не путайте семантический hook с гарантией неизменности.
  • Beautiful Soup documentation — прочитайте разделы Making the soup, parser differences, navigating и CSS selectors; это основной API-справочник артефакта.
  • Soup Sieve: selectors — сверьте поддерживаемый Beautiful Soup CSS-синтаксис и ограничения конкретного selector engine.
  • WHATWG HTML: parsing — используйте как первичный источник о том, как HTML превращается в дерево и почему исправление malformed markup не тривиально.
  • WHATWG DOM Standard — уточните модель nodes и trees; отделяйте стандарт DOM от Python parse tree и визуального представления страницы.
  • W3C Selectors Level 4 — обращайтесь к спецификации, когда нужна точная семантика matching, а не только пример библиотечного вызова.
  • RFC 9309: Robots Exclusion Protocol — прочитайте область действия протокола и его security considerations до проектирования crawler-а.
  • Python: html.parser — проверьте поведение выбранного встроенного parser и явно учитывайте, что он не проверяет соответствие документа HTML-стандарту.

Quiz · 5 вопроса

Проверьте себя

Ответьте после практики. Объяснение появится сразу после выбора.

01

Почему artifact сначала ищет container, затем records и только потом fields?

Scoped search связывает field с конкретным списком и конкретной записью.

02

Обязательный selector amount дал два совпадения внутри одной карточки. Как трактовать результат?

Для обязательного поля договор требует ровно один узел; два совпадения не дают доказанного mapping.

03

Что изменит `--allow-failures` для невалидного HTML-аудита?

Диагностический режим влияет на exit code, а quality gate публикации остаётся закрытым.

04

Почему parser и SHA-256 исходного HTML входят в provenance?

Дерево зависит от входных bytes и parser; provenance связывает snapshot с обоими.

05

Карточки появляются только после выполнения JavaScript в браузере. Какой вывод корректен?

Beautiful Soup парсит переданный HTML и не исполняет JavaScript; нужен другой согласованный источник или отдельный инструмент.

        self.contract = json.loads(CONTRACT.read_text(encoding="utf-8"))
        self.html = VALID.read_text(encoding="utf-8")

    def extract_text(
        self,
        html: str,
        *,
        contract: dict | None = None,
    ) -> dict:
        with TemporaryDirectory() as directory:
            root = Path(directory)
            html_path = root / "fixture.html"
            contract_path = root / "contract.json"
            html_path.write_text(html, encoding="utf-8")
            contract_path.write_text(
                json.dumps(contract or self.contract, ensure_ascii=False), encoding="utf-8"
            )
            return EXTRACTOR.extract_html(html_path, contract_path)

    def test_valid_fixture_matches_selector_contract(self) -> None:
        result = EXTRACTOR.extract_html(VALID, CONTRACT)
        self.assertTrue(result["summary"]["valid"])
        self.assertEqual(result["summary"]["failed_checks"], [])
        self.assertEqual(result["summary"]["record_count"], 2)

    def test_records_have_declared_grain_and_decimal_type(self) -> None:
        result = EXTRACTOR.extract_html(VALID, CONTRACT)
        self.assertEqual(
            result["records"],
            [
                {"order_id": "O2601", "user_id": "U001", "amount": Decimal("1200.50")},
                {"order_id": "O2602", "user_id": "U002", "amount": Decimal("950.00")},
            ],
        )

        result = EXTRACTOR.extract_html(VALID, CONTRACT)

        self.assertEqual(result["source"]["file_name"], "orders.html")
        self.assertEqual(len(result["source"]["sha256"]), 64)
        self.assertEqual(len(result["contract_source"]["sha256"]), 64)

def exactly_one(scope: Tag | BeautifulSoup, selector: str, label: str) -> Tag:
    matches = scope.select(selector)
    if len(matches) != 1:
        raise ValueError(f"{label}: expected one match, got {len(matches)}")
    return matches[0]

from __future__ import annotations

import argparse
import hashlib
import json
import os
import re
import sys
import tempfile
from collections.abc import Iterable
from decimal import Decimal, InvalidOperation
from pathlib import Path
from typing import Any

import soupsieve
from bs4 import BeautifulSoup

CONTRACT_VERSION = "2.0.0"
SUPPORTED_PARSER = "html.parser"
SUPPORTED_ENCODING = "utf-8"
DECIMAL_PATTERN = re.compile(r"^[+-]?\d+(?:\.\d+)?$")
TOP_LEVEL_KEYS = {
    "version",
    "parser",
    "encoding",
    "container_selector",
    "record_selector",
    "record_count",
    "record_id",
    "fields",
}


class HtmlContractError(ValueError):
    """Raised when configuration or input bytes cannot be inspected safely."""


def _object_without_duplicates(pairs: list[tuple[str, Any]]) -> dict[str, Any]:
    result: dict[str, Any] = {}
    for key, value in pairs:
        if key in result:
            raise HtmlContractError(f"duplicate JSON key: {key}")
        result[key] = value
    return result


def _require_keys(value: Any, expected: set[str], label: str) -> dict[str, Any]:
    if not isinstance(value, dict):
        raise HtmlContractError(f"{label} must be an object")
    missing = expected - set(value)
    unknown = set(value) - expected
    if missing:
        raise HtmlContractError(f"{label} misses keys: {sorted(missing)}")
    if unknown:
        raise HtmlContractError(f"{label} has unknown keys: {sorted(unknown)}")
    return value


def _non_blank_string(value: Any, label: str) -> str:
    if not isinstance(value, str) or not value.strip():
        raise HtmlContractError(f"{label} must be a non-blank string")
    return value


def _validate_selector(value: Any, label: str) -> str:
    selector = _non_blank_string(value, label)
    try:
        soupsieve.compile(selector)
    except soupsieve.SelectorSyntaxError as error:
        raise HtmlContractError(f"{label} is not a valid CSS selector: {error}") from error
    return selector


def _parse_contract(raw: bytes) -> dict[str, Any]:
    try:
        text = raw.decode(SUPPORTED_ENCODING, errors="strict")
    except UnicodeDecodeError as error:
        raise HtmlContractError(f"contract is not valid UTF-8 at byte {error.start}") from error
    try:
        value = json.loads(text, object_pairs_hook=_object_without_duplicates)
    except json.JSONDecodeError as error:
        raise HtmlContractError(f"invalid contract JSON: {error.msg}") from error

    contract = _require_keys(value, TOP_LEVEL_KEYS, "contract")
    if contract["version"] != CONTRACT_VERSION:
        raise HtmlContractError(
            f"unsupported contract version: {contract['version']!r}; expected {CONTRACT_VERSION!r}"
        )
    if contract["parser"] != SUPPORTED_PARSER:
        raise HtmlContractError(
            f"unsupported parser: {contract['parser']!r}; expected {SUPPORTED_PARSER!r}"
        )
    if str(contract["encoding"]).lower() != SUPPORTED_ENCODING:
        raise HtmlContractError(
            f"unsupported encoding: {contract['encoding']!r}; expected {SUPPORTED_ENCODING!r}"
        )
    _validate_selector(contract["container_selector"], "container_selector")
    _validate_selector(contract["record_selector"], "record_selector")

    count = _require_keys(contract["record_count"], {"mode", "value"}, "record_count")
    if count["mode"] not in {"exact", "min"}:
        raise HtmlContractError("record_count.mode must be 'exact' or 'min'")
    if isinstance(count["value"], bool) or not isinstance(count["value"], int):
        raise HtmlContractError("record_count.value must be an integer")
    if count["value"] < 1:
        raise HtmlContractError("record_count.value must be at least 1")

    record_id = _require_keys(contract["record_id"], {"name", "attribute"}, "record_id")
    _non_blank_string(record_id["name"], "record_id.name")
    _non_blank_string(record_id["attribute"], "record_id.attribute")

    fields = contract["fields"]
    if not isinstance(fields, dict) or not fields:
        raise HtmlContractError("fields must be a non-empty object")
    if record_id["name"] in fields:
        raise HtmlContractError("record_id.name must not collide with a field name")
    for name, raw_field in fields.items():
        _non_blank_string(name, "field name")
        if not isinstance(raw_field, dict):
            raise HtmlContractError(f"field {name!r} must be an object")
        source = raw_field.get("source")
        expected_keys = {"selector", "source", "type", "non_blank"}
        if source == "attribute":
            expected_keys.add("attribute")
        field = _require_keys(raw_field, expected_keys, f"field {name!r}")
        _validate_selector(field["selector"], f"field {name!r}.selector")
        if source not in {"text", "attribute"}:
            raise HtmlContractError(f"field {name!r}.source must be 'text' or 'attribute'")
        if source == "attribute":
            _non_blank_string(field["attribute"], f"field {name!r}.attribute")
        if field["type"] not in {"string", "decimal"}:
            raise HtmlContractError(f"field {name!r}.type must be 'string' or 'decimal'")
        if not isinstance(field["non_blank"], bool):
            raise HtmlContractError(f"field {name!r}.non_blank must be boolean")
    return contract


def load_contract(path: str | Path) -> dict[str, Any]:
    contract_path = Path(path)
    try:
        raw = contract_path.read_bytes()
    except OSError as error:
        raise HtmlContractError(
            f"cannot read contract file {contract_path.name!r}: {error}"
        ) from error
    return _parse_contract(raw)


def _convert(value: str, value_type: str) -> str | Decimal:
    if value_type == "string":
        return value
    if value_type == "decimal":
        if not DECIMAL_PATTERN.fullmatch(value):
            raise HtmlContractError(f"invalid decimal: {value!r}")
        try:
            number = Decimal(value)
        except InvalidOperation as error:
            raise HtmlContractError(f"invalid decimal: {value!r}") from error
        if not number.is_finite():
            raise HtmlContractError(f"decimal must be finite: {value!r}")
        return number
    raise HtmlContractError(f"unsupported field type: {value_type}")


def _record_count_matches(actual: int, policy: dict[str, Any]) -> bool:
    if policy["mode"] == "exact":
        return actual == policy["value"]
    return actual >= policy["value"]


def extract_html(
    input_path: str | Path,
    contract_path: str | Path,
    *,
    max_bytes: int = 5_000_000,
) -> dict[str, Any]:
    """Audit one saved HTML document without publishing partial records."""

    if isinstance(max_bytes, bool) or not isinstance(max_bytes, int) or max_bytes < 1:
        raise HtmlContractError("max_bytes must be a positive integer")
    path = Path(input_path)
    contract_file = Path(contract_path)
    try:
        contract_raw = contract_file.read_bytes()
    except OSError as error:
        raise HtmlContractError(
            f"cannot read contract file {contract_file.name!r}: {error}"
        ) from error
    contract = _parse_contract(contract_raw)
    try:
        raw = path.read_bytes()
    except OSError as error:
        raise HtmlContractError(f"cannot read HTML file {path.name!r}: {error}") from error
    if len(raw) > max_bytes:
        raise HtmlContractError(f"HTML exceeds max_bytes: {len(raw)} > {max_bytes}")
    try:
        text = raw.decode(SUPPORTED_ENCODING, errors="strict")
    except UnicodeDecodeError as error:
        raise HtmlContractError(f"HTML is not valid UTF-8 at byte {error.start}") from error

    soup = BeautifulSoup(text, contract["parser"])
    containers = soup.select(contract["container_selector"])
    charset_nodes = soup.select("meta[charset]")
    charset_matches = len(charset_nodes) == 1 and str(
        charset_nodes[0].get("charset", "")
    ).lower() in {"utf-8", "utf8"}
    errors: list[dict[str, Any]] = []
    if not charset_matches:
        errors.append(
            {
                "kind": "document",
                "field": "charset",
                "matches": len(charset_nodes),
                "error": "expected exactly one UTF-8 meta charset declaration",
            }
        )
    if len(containers) != 1:
        errors.append(
            {
                "kind": "container",
                "selector": contract["container_selector"],
                "matches": len(containers),
                "error": "container selector must match exactly one node",
            }
        )
    nodes = containers[0].select(contract["record_selector"]) if len(containers) == 1 else []
    count_matches = _record_count_matches(len(nodes), contract["record_count"])
    if not count_matches:
        errors.append(
            {
                "kind": "record_count",
                "actual": len(nodes),
                "policy": contract["record_count"],
                "error": "record count does not satisfy the contract",
            }
        )

    records: list[dict[str, Any]] = []
    selector_counts: dict[str, list[int]] = {name: [] for name in contract["fields"]}
    present_ids = True
    fields_valid = True
    id_name = contract["record_id"]["name"]
    id_attribute = contract["record_id"]["attribute"]
    for position, node in enumerate(nodes, start=1):
        raw_id = node.get(id_attribute)
        record_id = str(raw_id).strip() if raw_id is not None else ""
        record: dict[str, Any] = {id_name: record_id or None}
        if not record_id:
            present_ids = False
            errors.append(
                {
                    "kind": "record_id",
                    "record": position,
                    "attribute": id_attribute,
                    "error": "record id attribute is missing or blank",
                }
            )
        for name, field in contract["fields"].items():
            matches = node.select(field["selector"])
            selector_counts[name].append(len(matches))
            if len(matches) != 1:
                fields_valid = False
                errors.append(
                    {
                        "kind": "field",
                        "record": position,
                        "record_id": record_id or None,
                        "field": name,
                        "selector": field["selector"],
                        "matches": len(matches),
                        "error": "field selector must match exactly one node",
                    }
                )
                record[name] = None
                continue
            match = matches[0]
            if field["source"] == "text":
                raw_value: Any = match.get_text(" ", strip=True)
            else:
                raw_value = match.get(field["attribute"])
            value = str(raw_value).strip() if raw_value is not None else ""
            if field["non_blank"] and not value:
                fields_valid = False
                errors.append(
                    {
                        "kind": "field",
                        "record": position,
                        "record_id": record_id or None,
                        "field": name,
                        "error": "selected value is missing or blank",
                    }
                )
                record[name] = None
                continue
            try:
                record[name] = _convert(value, field["type"])
            except HtmlContractError as error:
                fields_valid = False
                errors.append(
                    {
                        "kind": "field",
                        "record": position,
                        "record_id": record_id or None,
                        "field": name,
                        "error": str(error),
                    }
                )
                record[name] = None
        records.append(record)

    ids = [record[id_name] for record in records if record[id_name] is not None]
    duplicate_ids = sorted({value for value in ids if ids.count(value) > 1})
    if duplicate_ids:
        errors.append(
            {
                "kind": "grain",
                "field": id_name,
                "values": duplicate_ids,
                "error": "record ids must be unique",
            }
        )
    checks = {
        "charset_declaration_matches": charset_matches,
        "container_exactly_one": len(containers) == 1,
        "record_count_matches": count_matches,
        "record_ids_present": present_ids and bool(nodes),
        "record_ids_unique": not duplicate_ids,
        "required_fields_valid": fields_valid and bool(nodes),
    }
    failed_checks = [name for name, passed in checks.items() if not passed]
    return {
        "source": {
            "file_name": path.name,
            "bytes": len(raw),
            "sha256": hashlib.sha256(raw).hexdigest(),
            "parser": contract["parser"],
            "encoding": SUPPORTED_ENCODING,
        },
        "contract": contract,
        "contract_source": {
            "file_name": contract_file.name,
            "sha256": hashlib.sha256(contract_raw).hexdigest(),
        },
        "records": records,
        "selector_counts": {
            "containers": len(containers),
            "records": len(nodes),
            "fields": selector_counts,
        },
        "errors": errors,
        "checks": checks,
        "summary": {
            "valid": not failed_checks,
            "published": False,
            "record_count": len(records),
            "failed_checks": failed_checks,
        },
    }


def json_default(value: Any) -> Any:
    if isinstance(value, Decimal):
        return str(value)
    raise TypeError(f"cannot serialize {type(value).__name__}")


def publish_snapshot(result: dict[str, Any], output: str | Path) -> Path:
    """Atomically publish one self-contained snapshot after a successful audit."""

    if not result.get("summary", {}).get("valid"):
        raise HtmlContractError("an invalid extraction result cannot be published")
    target = Path(output)
    target.parent.mkdir(parents=True, exist_ok=True)
    published = json.loads(json.dumps(result, ensure_ascii=False, default=json_default))
    published["summary"]["published"] = True
    payload = json.dumps(published, ensure_ascii=False, indent=2, sort_keys=True) + "\n"
    descriptor, temporary_name = tempfile.mkstemp(
        prefix=f".{target.name}.", suffix=".part", dir=target.parent
    )
    temporary = Path(temporary_name)
    try:
        with os.fdopen(descriptor, "w", encoding="utf-8", newline="\n") as stream:
            stream.write(payload)
            stream.flush()
            os.fsync(stream.fileno())
        os.replace(temporary, target)
    except Exception:
        temporary.unlink(missing_ok=True)
        raise
    return target


def extract_and_publish(
    input_path: str | Path,
    contract_path: str | Path,
    output: str | Path,
    *,
    max_bytes: int = 5_000_000,
) -> dict[str, Any]:
    result = extract_html(input_path, contract_path, max_bytes=max_bytes)
    publish_snapshot(result, output)
    result["summary"]["published"] = True
    return result


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(description="Audit and publish saved HTML records")
    parser.add_argument("--input", required=True, type=Path)
    parser.add_argument("--contract", required=True, type=Path)
    parser.add_argument("--output", type=Path)
    parser.add_argument("--max-bytes", type=int, default=5_000_000)
    parser.add_argument(
        "--allow-failures",
        action="store_true",
        help="return zero for a failed audit; invalid records are still never published",
    )
    return parser


def main(argv: Iterable[str] | None = None) -> int:
    arguments = build_parser().parse_args(argv)
    try:
        result = extract_html(
            arguments.input,
            arguments.contract,
            max_bytes=arguments.max_bytes,
        )
        if result["summary"]["valid"] and arguments.output:
            publish_snapshot(result, arguments.output)
            result["summary"]["published"] = True
    except HtmlContractError as error:
        print(json.dumps({"error": str(error)}, ensure_ascii=False, indent=2))
        return 2
    except OSError as error:
        print(
            json.dumps({"error": f"cannot publish snapshot: {error}"}, ensure_ascii=False, indent=2)
        )
        return 2
    print(json.dumps(result, ensure_ascii=False, indent=2, default=json_default))
    if not result["summary"]["valid"] and not arguments.allow_failures:
        return 1
    return 0


if __name__ == "__main__":
    sys.exit(main())
